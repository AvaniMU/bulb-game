# Bulb Game

An interactive browser-based game where users control a virtual bulb through interactive actions and visual feedback.

## Features

- Interactive bulb controls
- Dynamic visual changes
- User interaction and event handling
- Simple and responsive interface
- Instant visual feedback

## Technologies

- HTML5
- CSS3
- JavaScript

## Project Purpose

This project was developed to practice **JavaScript event handling, DOM manipulation, conditional logic, and interactive UI development** through a simple browser-based game.

## Learning Outcomes

- Improved understanding of DOM manipulation
- Practiced JavaScript event handling
- Learned to create dynamic visual interactions
- Strengthened frontend development skills
